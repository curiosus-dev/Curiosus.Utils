## Options

`TempFileOptions` of `Curiosus.Tools` 3.0 moved to `Microsoft.Extensions.Options`, see the
[Curiosus.Tools 3.0 migration notes](../curiosus-tools/3.0.md#options). `AddSharpZipArchiver` takes an optional
`Action<TempFileOptions>` instead of an instance and returns the options builder; the options are validated when the
host starts instead of on registration.

Before:

```csharp
var tempFileOptions = builder.Configuration.GetSection("TempFiles").Get<TempFileOptions>() ?? new TempFileOptions();
builder.Services.AddSharpZipArchiver(tempFileOptions);
```

After:

```csharp
builder.Services.AddSharpZipArchiver().BindConfiguration("TempFiles");
```

`AddSharpZipArchiver` registers the temp file services of `Curiosus.Tools` (`AddTempFileServices`); `AddTempDirCleaner`
of `Curiosus.Hosting` shares the same options, so bind the section once. `SharpZipArchiver` takes
`IOptions<TempFileOptions>`: code that creates it by hand passes `Options.Create(tempFileOptions)`.

Checklist:

- [ ] `AddSharpZipArchiver(options)` → `AddSharpZipArchiver().BindConfiguration("TempFiles")`.
- [ ] `new SharpZipArchiver(factory, options)` → `new SharpZipArchiver(factory, Options.Create(options))`.
- [ ] Update `Curiosus.Tools` to 3.0 in the same step.
